Reins

Your coding agent, in your pocket.

The DeepSeek Harness runs on your Mac, where your code and your keys already are. Reins is the iPhone app that drives it — read what it did, approve what it wants to do next, start the next thing from a train.

How it fits together

Three pieces. Reins is the app on your phone. Bridle is a small program on your Mac that talks to the Harness for it. Between them, when they are not on the same Wi-Fi, sits a relay we run.

The relay is a switchboard, not a middleman. The app and Bridle set up an encrypted channel with each other and the relay forwards the sealed bytes without being able to open them. That is a property of the design, not a promise about our conduct — see what the relay can and cannot see.

On the same Wi-Fi, the app skips the relay entirely and talks to your Mac directly.

Setting up

  1. Install Bridle on the Mac

    Paste this into Terminal. It takes about a minute.

    curl -fsSL https://reins.novabox.ai/install | sh

  2. Start pairing

    Still in Terminal:

    bridle pair

    A QR code appears, with a short code underneath it.

  3. Point the phone at it

    Open Reins, tap Connect, and scan. If the camera is being difficult, type the short code instead. Pairing is one-time — after this the app reconnects on its own.

What it does

Approvals When the agent wants to run something, the request arrives with the full command and diff. Approve or refuse. Anything raised while you were away is waiting when you come back — and sits above everything else in the list, where it cannot be scrolled past or folded away.
Sessions Everything the Harness is running, grouped by workspace. Start new ones, branch from where a conversation got interesting, archive what is done.
Reading Diffs, tool output, file reads, and to-do lists rendered for a phone screen rather than shrunk to fit one.
Trace The whole run as one line per step, searchable, with what each one took. For the two questions a transcript cannot answer at a glance: what has it been doing, and where did it go wrong.
Cost and context How full the context window is and what is filling it, turns and steps, time to first token, and the four token classes broken out — because cache reads and fresh input are an order of magnitude apart in price.
Control Pick the model and how hard it thinks. Change what the agent is allowed to touch. Run the skills installed on your Mac by typing /.
Subagents When work is handed to a child agent, see what it is doing instead of watching a tool call sit there.
Several Macs Pair as many as you like and switch between them.
